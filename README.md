# Wallet Checker

`gui.py` и `utility.py` находятся в одной папке. Интерфейс передаёт утилите
команды `balances` и `labels`, сети `evm`, `btc`, `tron`, `solana`, файлы входа,
путь результата, лимит транзакций, настройку кэша и необязательный файл ключей.

## Запуск в Ubuntu

1. Распакуйте проект в постоянную папку, доступную для записи.
2. В свойствах `Setup.sh` → «Права» разрешите выполнение файла как программы.
   Откройте его через «Запустить как программу» в контекстном меню.
   Однократная установка откроет окно с ходом установки; команды вводить не нужно.
   Нужен интернет, для установки компонентов Python может потребоваться пароль sudo.
3. После сообщения «Готово» откройте **Wallet Checker** в меню приложений Ubuntu.
   Либо скопируйте созданный `Wallet Checker.desktop` на рабочий стол и выберите
   «Разрешить запуск», затем открывайте двойным щелчком.
4. Интерфейс откроется в браузере без терминала. Маленькое окно Wallet Checker
   оставьте открытым. Для завершения нажмите «Закрыть программу» в этом окне.
   Это завершит и текущую проверку: сначала сохраните нужные результаты.

Если сервер не запустился, смотрите `launcher.log`. После перемещения папки
повторите `Setup.sh`, чтобы обновить пути ярлыков. Установка рассчитана на
Ubuntu Desktop с Python 3.10+ и `x-terminal-emulator`.

## Ключи и результаты

Загрузите файл с ключами в интерфейсе или положите `keys.txt` / `.env` рядом с
`utility.py`. Формат: одна строка `ИМЯ=значение` на ключ. Рабочие файлы сохраняются
в `work`, сохранённые результаты — в `results`. Эти папки могут содержать ключи
и данные: не публикуйте их. В исходной утилите значения ключей также попадают
в файл прогресса и отображаются в интерфейсе.

## Проверка совместимости

`python -m unittest discover -s tests -v` проверяет все 160 комбинаций команды,
сети, лимита и кэша, каждую с файлом ключей и без него, используя реальное
выражение аргументов из GUI и парсер утилиты.

Совместимость CLI не подтверждает работу внешних API. В исходной утилите
остались отметки `CHECK` для Apify, GMGN и Arkham; для EVM и Solana не заданы
пути полей статистики. Tron, GMGN и Arkham принимают параметр лимита внутри
Python, но не передают его в HTTP-запрос. `DEBANK_KEY` читается, но не используется.
